# Predictive-Food-Waste-Analytics-for-Restaurant-Operations
**Overview**

Developed a Machine Learning-powered Food Waste Analytics Platform to help restaurants forecast food wastage, optimize food preparation, and improve resource utilization. The solution combines predictive analytics, data visualization, and intelligent recommendations to support data-driven operational decision-making.

**Business Problem**

Restaurants often face challenges in accurately forecasting food demand, leading to overproduction, increased operational costs, inventory inefficiencies, and significant food wastage.

This project addresses these challenges by leveraging historical restaurant data to predict food wastage before events occur, enabling proactive planning and waste reduction strategies.

**Solution**

Analyzed restaurant food wastage patterns using Python and MongoDB.
Built a predictive analytics model using XGBoost Regressor to estimate expected food waste.
Developed interactive dashboards for waste monitoring, trend analysis, and operational insights.
Generated data-driven recommendations to support inventory optimization and waste reduction initiatives.

**Tech Stack**


Programming: Python
Database: MongoDB
Machine Learning: XGBoost, Scikit-Learn
Backend: Flask
Visualization: Plotly, Chart.js
Tools: Jupyter Notebook, VS Code

**Key Features**


Food Waste Forecasting
Event-Based Waste Analysis
Interactive Analytics Dashboard
Waste Reduction Recommendations
Inventory Planning Support

**Machine Learning**


Model: XGBoost Regressor

Target Variable: Wastage_Food_Amount

Input Features:

Number of Guests
Event Type
Food Type
Storage Conditions
Geographical Location
Quantity of Food Prepared


**Outcomes**


Identified key factors contributing to food wastage across restaurant events.
Predicted expected food waste using historical operational data.
Improved food preparation planning and inventory management decisions.
Supported cost optimization and sustainability initiatives through data-driven insights.
